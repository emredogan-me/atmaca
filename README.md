# Atmaca Linux

Fedora tabanlı, KDE Plasma masaüstlü, kimliği %100 Atmaca olan bir Linux dağıtımı.

- Taban: en güncel kararlı Fedora + Fedora'nın güncel çekirdeği
- Masaüstü: KDE Plasma
- Paket yöneticisi: başta `dnf`, sonra kendi aracımız `atmc`
- Çıktı: `atmaca.iso` (USB'den canlı açılır, diske kurulur)

Yol haritası: [docs/00-yol-haritasi.md](docs/00-yol-haritasi.md)
